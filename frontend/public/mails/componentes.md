# Sistema de componentes

Todos los componentes viven dentro de una tabla exterior de 600 px y usan estilos inline. En la plantilla se identifican con comentarios `COMPONENTE:`.

| Componente | Propósito | Campos editables |
|---|---|---|
| Preheader | Resumen invisible en bandeja | Texto de 80–120 caracteres |
| Masthead | Reconocimiento de marca | Nombre, número, fecha |
| Hero | Tema y emoción principal | Imagen, tema, promesa |
| Introducción | Tesis de la edición | 2–4 párrafos |
| Informe del coach | Voz personal/experta | Autor, título, cuerpo, cita |
| Principio | Idea central transferible | Título, explicación, recordatorio |
| Perspectiva | Aplicación técnica | Título, cuerpo, lista opcional |
| Sabiduría | Fe/reflexión | Referencia, cita, reflexión |
| Misión | Conducta semanal | Acción, pasos, cierre |
| El estándar | Frase memorable | Una frase y una línea de apoyo |
| Comunidad | Participación y reconocimiento | Pregunta, instrucciones, usuario social |
| Próximo objetivo | Anticipo | Próximo tema y una frase |
| Reflexión | Pregunta de cierre | Una pregunta |
| Compartir | Crecimiento orgánico | URL web y `mailto:` |
| CTA WhatsApp | Conversión | Número, mensaje, botón |
| Footer | Confianza y cumplimiento | Dirección, redes, preferencias |

## Reglas de edición

- Cada bloque debe poder eliminarse completo sin romper la tabla exterior.
- Limitar cada párrafo a 3–5 líneas visuales cuando sea posible.
- Usar listas con filas de tabla, no viñetas complejas.
- Reservar el bloque azul profundo para Sabiduría, Estándar o cierre, no para todos.
- Mantener Compartir como acción secundaria de texto y WhatsApp como único botón grande.
